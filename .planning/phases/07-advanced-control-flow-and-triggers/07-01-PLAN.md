<objective>Add minimal branch semantics and readable branch UI without introducing a canvas engine.</objective>

<threat_model>
<threat severity="high" id="T-07-01">A malformed branch could create hidden cycles or skip already-executed steps, making run history misleading.</threat>
<mitigation>Validate branch skip targets before publish so targets must exist after the branch step in the ordered definition and cannot include the branch step itself or earlier steps.</mitigation>
<threat severity="medium" id="T-07-02">A branch could silently suppress important work without operators understanding why downstream steps did not run.</threat>
<mitigation>Persist skipped step runs and step events with the branch step key and path label as the skip reason; include branch output in run detail.</mitigation>
<threat severity="medium" id="T-07-03">A branch condition could expose sensitive output values in logs or events.</threat>
<mitigation>Branch events contain only matched state, selected path label, and skipped step keys. Detailed evaluated values remain in redacted run output only.</mitigation>
</threat_model>
