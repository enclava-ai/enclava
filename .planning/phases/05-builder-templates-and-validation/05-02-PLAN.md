<objective>Build the typed linear Step Builder UI and lifecycle action plumbing for draft save, validation, publish, and enable flows.</objective>

<threat_model>
<threat severity="medium">Builder actions could bypass workflow permissions or audit if the frontend writes directly to backend internals incorrectly.</threat>
<mitigation>Route all create/update/publish/enable actions through `frontend/src/app/api/workflows/route.ts` and existing authenticated internal lifecycle endpoints.</mitigation>
<threat severity="medium">Users could publish a malformed workflow if frontend state is serialized differently from backend schemas.</threat>
<mitigation>Normalize all builder state into `WorkflowDefinitionDocument` and call `workflowApi.validateDefinition` before publish.</mitigation>
</threat_model>
