<objective>Add the connector sync workflow step type, builder configuration, actionable runtime errors, and Connector Intake Triage authoring/run support.</objective>

<threat_model>
<threat severity="high">Workflow definitions could leak connector credentials if connector config is copied into step config.</threat>
<mitigation>Step config stores only `connector_id`, sync mode, and output limits. The handler loads credentials through the existing connector service.</mitigation>
<threat severity="medium">A workflow run could continue after connector sync failed because the connector service records a failed job instead of raising.</threat>
<mitigation>The workflow handler inspects the returned job/status and raises `WorkflowStepExecutionError` when status is failed, preserving job id and error text.</mitigation>
<threat severity="medium">Downstream agent prompts could receive huge connector payloads.</threat>
<mitigation>Limit output item count and artifact payload size in the workflow adapter, with a backend max even if frontend sends a larger value.</mitigation>
</threat_model>
