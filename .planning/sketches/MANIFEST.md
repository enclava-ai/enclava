# Sketch Manifest

## Design Direction

Workflow UX should feel like a quiet operations surface for confidential AI automation: dense enough for repeated use, explicit about schedule/run state, and clear about when an agent is only one step inside a broader governed process.

## Reference Points

- Existing Enclava Slate Mono admin/dashboard surfaces.
- Operational automation tools where runs, schedules, logs, and retries are first-class.
